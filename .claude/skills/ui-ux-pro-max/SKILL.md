# UI/UX Pro Max

Use this skill when the task changes how a feature looks, feels, moves, or is interacted with.

## When to Use

- Building or refining dashboards, portals, admin panels, landing pages, and form-heavy UIs
- Reviewing existing UI for usability, accessibility, or visual polish
- Improving layout, typography, spacing, color, motion, or component states
- Designing responsive screens for desktop and mobile

## Workflow

1. Identify the product type, target audience, and style direction.
2. Check whether a local design system or page-specific guidance already exists.
3. Apply mobile-first layout, accessible states, and clear hierarchy.
4. Keep interactions predictable and avoid unnecessary visual noise.
5. Validate contrast, touch targets, spacing rhythm, and responsive behavior before delivery.

## Practical Rules

- Prefer clear hierarchy over decorative clutter.
- Use semantic color meaning and do not rely on color alone.
- Keep touch targets large enough for mobile use.
- Preserve consistent spacing and alignment across screens.
- Make loading, empty, and error states explicit.
- Keep existing stack conventions intact; in this repo that means Next.js + Tailwind patterns.

## For This Workspace

When editing the novelty job tracking portal:
- Preserve the current brand palette and layout language.
- Keep admin flows fast and information-dense.
- Make client tracking readable at a glance, with clear stage states and timestamps.
- Avoid breaking the existing job/stage data flow.
